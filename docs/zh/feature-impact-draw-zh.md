# 各指标对「平」的影响

本文件是三分类模型（负 = 0，平 = 1，胜 = 2）的逐类别 SHAP 分析，只说明模型对「平」这一类的归因；另外两类请见对应文件。

## 分析设置

- **数据**：`data/match_features.csv`，208 条球队-场次记录，131 个指标；5 折 `StratifiedKFold`（`random_state=42`）。
- **编号**：指标在 `feature-dictionary-zh.md` 中的编号（#4–#134），与字典表格的「#」列一致。
- **模型**：`XGBClassifier`（500 棵树，最大深度 5，学习率 0.04，`multi:softprob`），与 `model/train.ipynb` 的配置一致。
- **重要性**：在每折的留出集（约 42 条记录）上计算「平」类的平均 |SHAP|。
- **方向**：指标值与该类 SHAP 值的 Spearman 相关（合并全部 208 条留出记录）。↑平 = 数值越高越推动「平」；↓平 = 数值越高越偏离「平」；— = |ρ| < 0.15，方向不明显。
- **稳定性**：核心 = 五折平均排名 ≤ 3；波动 = 至少 2 折进入前 40 且至少 2 折跌出前 80；单次极端 = 仅 1 折进入前 40 且平均排名 > 40；稳定 = 平均排名 ≤ 20 且排名极差 ≤ 25；不稳定 = 排名极差 ≥ 60；中等 = 平均排名 ≤ 40；其余为低。
- **类别分布**：负 80 条、平 48 条、胜 80 条（共 208 条）。
- **参考性能**：五折准确率 0.779 ± 0.068，宏平均 F1 0.747 ± 0.070。

## 主要结论

- 前 3 个指标占「平」类 SHAP 总量的 **16.9%**，前 10 个占 **36.9%**。
- **2** 个指标为「核心」，**10** 个为「波动」，**25** 个仅依赖单折。
- SHAP 值属于条件归因：方向描述的是该模型内部的边际推动，不等同于原始相关系数。

- `进球` 本身就是进球结果（见 `data/report-data-schema.md` 第 1 条注释），其主导地位有一定循环性。
- 每折 SHAP 仅基于约 42 条记录，重要性估计叠加了抽样噪声与模型差异。
